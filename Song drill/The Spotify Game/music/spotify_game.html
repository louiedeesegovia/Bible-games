📋 Mechanics

How The Spotify Game works

🎵

3 Rounds

Each round features a different Christmas song with a unique challenge type.

✍️

Round 1

Fill in the missing lyric. Type or say the correct word to score.

🅰️

Round 2

Pick the correct version of the lyric — A or B.

🖼️

Round 3

Guess the missing lyric using picture clues.

🔀

Steal Rule

If the active contestant answers incorrectly, the other contestant may steal the point.

⭐ Score Rules

Points up for grabs each round

1️⃣

Round 1

1 point for each correct lyric guess.

2️⃣

Round 2

2 points for choosing the correct lyrics.

3️⃣

Round 3

3 points for guessing exact/missing words from the picture.

🔀

Steal Opportunity

Wrong answer = other contestant gets a chance to answer for full points.
